# Insulation Library

Interactive, photoreal 3D library of mechanical insulation: pipe insulation materials, jacketing, fittings and removable blankets, with specs taken from manufacturer data sheets.

## What it does

- **Materials:** calcium silicate, fiberglass, mineral wool, cellular glass, elastomeric and phenolic, each built to field practice. That covers half-shells or hinged sections, section lengths, joint staggering, and double layers above 3" (2½" for phenolic).
- **Layer-by-layer build-up:** pipe → insulation → facing → vapor retarder → jacket, each one selectable (click it in the list or on the model), hideable, or "peeled to" so you see what is underneath.
  - Hot or cold service decides the vapor retarder: the ASJ facing on fibrous systems, the closed-cell foam itself on elastomerics, or a separate sealed membrane (cellular glass; phenolic under metal).
  - No screws through a vapor retarder on cold work.
- **Facing and jacketing:** factory ASJ facing, plus smooth or stucco aluminum, stainless and PVC outer jackets.
  - Real laps, bands with wing seals, and screws on hot work.
  - Jacket gauge set from the JM Metal Jacketing Install Guide.
- **Components:**
  - Straight run.
  - 90° elbow: pressed covers with throat pleats through 12" NPS, gored covers above, and PVC fitting covers.
  - Flanged gate valve with a removable blanket.
- **Views:** Installed, Cutaway, Layers (a telescoping step-down with spec-driven callouts), Exploded (each layer's top half lifts off) and Section (every layer cut square, labelled ring by ring).
- **Settings:** studio, outdoor plant, and mechanical room.
- **Photo mode:** progressive path tracing ([three-gpu-pathtracer](https://github.com/gkjohnson/three-gpu-pathtracer)) with denoising and depth of field.
- **Spec data card:** service temperature, k-factor at a stated mean temperature, density, ASTM standards, moisture and vapor behaviour, application tags, and jacket compatibility and temperature limits. It follows the current selection. Every value comes from `research/materials-verified.json` or `research/jackets-verified.json`, with a link to its source.

## Simulator (Phase 1)

Three simulation modes sit beside the library (**Explore**), switched from the bar at the top:

- **Hot Pipe:** heat loss bare vs insulated, % reduction, outer surface temperature, annual energy, and personnel protection. The safe-touch limit is 140°F, which NIA cites as "standard industry practice".
- **Cold Pipe:** heat gain, dew point, margin to condensation, and a Dry / At risk / Sweating status.
- **Condensate:** sweating and dripping control. Status is Dry / Borderline / Sweating / Dripping risk, with the estimated condensate in fl oz per day per 10 ft, and one tap auto-sizes the insulation.

**Each mode includes:**
- Presets.
- Live sliders.
- Compare: 2–3 synced panels showing bare / current / recommended or any thickness.
- Thickness solvers.
- A thermal false-colour view with the dew-point isotherm drawn inside the insulation.
- Plain-English explanations, a Learn section, and an assumptions and sources footer on every result.

**3D effects follow the calculation:**
- Soft orange heat waves rise off hot surfaces.
- Blue airflow arrows carry heat into cold ones.
- Condensate beads form, run down and drip only while the computed surface is below the dew point.
- All of these thin out as heat flux drops.

**Phase 2 adds:**
- **Fittings:** tee (fish-mouthed branch, collar over the run) and bolted flange pair (weld-neck flanges with a removable blanket), alongside the elbow and valve. The simulator runs on every component; valves and flanges can be covered or left bare. Fitting heat flow uses an equivalent length of straight pipe: the Illinois TRM table for elbows and tees, and ASTM C1129 bare areas (class 150) for valves and flanges (`tools/build_fittings.py` ← `research/fittings-verified.json`). That reproduces Hart's and the TRM's published lengths, and lands about 10–25% above DOE Steam Tip Sheet #17's valve-cover savings.
- **New materials:** polyisocyanurate (Kingspan Tarecpir 2.0, JM Trymer 2000XP), aerogel blanket (Aspen Pyrogel XTE, Cryogel Z, in 10 mm wraps), expanded perlite (JM Sproule WR-1200, Howred GOODTEMP) and polyolefin tube (Armacell Tubolit, K-FLEX PE). Their specs are generated by `tools/build_specs2.py` from `research/materials2-verified.json`.
- **Thickness design:** every requirement is solved on its own and the largest governs:
  - personnel protection;
  - jacket and facing temperature limits;
  - condensation control;
  - optionally, the ASHRAE 90.1-2019 minimum with its conductivity correction (`research/vapor-code-verified.json`).

  Each requirement shows its source and the calculated exact minimum, and **Compare materials** sizes every suitable material for the same conditions.
- **Vapor retarders:**
  - the build-up's published permeance is checked against ASHRAE's ≤0.02 perm guidance (≤0.01 below 0°F);
  - an estimate of the water vapor that diffuses through it each year with sealed joints;
  - how deep into the insulation it's colder than the dew point.

**Phase 3 adds:**
- **Deeper 3E Plus validation**, locked by `npm test` against `app/src/sim/validationSummary.json` and shown in the app under "How accurate is this?":
  - JM's 3E Plus personnel-protection tables (wind, weathered aluminum, 300–1200°F, three products): 443/480 thicknesses exact, 480/480 within ½".
  - ASHRAE Refrigeration thickness tables: 1,372/1,440 within ½".
  - Run `UPDATE_VALIDATION=1 npm test` to accept a deliberate change.
- **Annual cost and payback:**
  - Heating: gas, purchased steam or electric, at your price and plant efficiency.
  - Cooling: electric at your $/kWh and kW/ton.
  - Simple payback from an installed cost per foot.
  - Defaults are examples, not sourced prices.
- **Scenarios:** save and reopen in the browser, share as a link (`#s=…`), or export and import JSON.
- **Side-by-side material comparison:** any compare panel can show another material at its design thickness, or open it from **Compare materials → 3D**.
- **Report:** one click gives a self-contained HTML report you can print to PDF. It includes 3D snapshots, inputs, results, the thickness design, the fitting and vapor checks, the accuracy table and every source.
- **Presentation mode:**
  - A customer-facing full-screen walkthrough: bare → insulated → side by side, on an auto-rotating model.
  - Large headline numbers, plus "Prepared for" from the report dialog.
  - ← / → to step, Esc to exit.

**Pipe materials (Phase 4): steel, copper and PVC.**
- **Copper:** Type L tube (ASTM B88) with sizes and walls from the CDA Copper Tube Handbook, copper-tube insulation ODs from ASTM C585, and 3E Plus emittance 0.6.
- **PVC:** Schedule 40 (ASTM D1785), with OD and minimum wall from the Charlotte, Spears and IPEX manuals.
  - The PVC wall's own resistance is modelled as a cylindrical shell at k = 1.2 Btu·in/hr·ft²·°F (ASTM C177, Charlotte and IPEX; Spears prints 1.02). As a result, a bare PVC line runs warmer than its fluid.
  - The app warns above PVC's published 140°F rating.
- **Metal walls:** neglected, as in C680, so the pipe surface sits at the fluid temperature.
- **Data:** `tools/build_pipes.py` generates `app/src/data/pipeWalls.ts` from `research/pipe-materials-verified.json` (G-ids). A test reproduces Charlotte's published PVC wall R-values.

**Ductwork (Phase 5): its own tab, driven by the energy codes.**
- **Inputs:** pick the duct type (supply, return, outside air, exhaust), where it runs and the climate zone.
- **Locations:**
  - The options are conditioned space, return plenum, unconditioned space, attic, crawl space, parking garage, outdoors and buried.
  - Each maps to its ASHRAE 90.1-2019 Table 6.8.2 column through the table's notes. Note b puts attics above insulated ceilings, crawl spaces and parking garages in the Exterior column; note c puts return plenums under Indirectly Conditioned; exception 2 exempts heated, semiheated or cooled spaces.
- **Location guide:** "Where does my duct run?" (also `?mode=duct&guide=1`) is a redrawn building section with DOE's 14 duct locations (BECP commercial duct-insulation guide, Figure 1). Pick one to see what ASHRAE 90.1-2019 and the IECC require there at your climate zone, any exception (short runouts, outlet backs, equipment casings, plenum walls) and what DOE's 2012 note said, then send it to the simulator.
- **Energy code:** choose ASHRAE 90.1-2019 or IECC 2021/2024 commercial (C403.12.1 / C403.13.1; outside the building R-8/R-12, unconditioned space R-6, exempt where the design ΔT is 15°F or less).
  - IECC readings that come from definitions rather than stated text (attics, crawl spaces and garages as "unconditioned space"; return plenums as conditioned) are flagged as derived.
- **Outside-air, exhaust and relief ducts:** neither code sets an R-value; both cover supply and return ducts only (`research/duct-code-verified.json`, D_C-ids). The IMC 603.12 condensation duty still applies, and the app checks it.
- **Design:** the code minimum is always part of the duct design; condensation is still checked.
- **Code minimum:** the result leads with the installed R the code requires (ASHRAE 90.1-2019 Table 6.8.2) and whether the insulation meets it.
- **Condensation:** checked whenever the duct air is colder than its surroundings.
- **Model:** rectangular ducts are solved face by face with the C680 flat-surface correlations. Sides are treated as vertical faces; the top and underside as horizontal faces, with the stable and unstable correlations swapped between warm and cold ducts. Round ducts are solved as cylinders.
- **Checks in `npm test`:** the correlations reproduce DNV's 12 C680 flat-surface rows and 3E Plus Example 5.
- **Insulation:**
  - Duct wrap uses Knauf Performance+ data at 25% compression (IMC 604.7) with an FSK facing, ε 0.1 per ASHRAE.
  - Elastomeric sheet uses AP ArmaFlex data.
  - The rated installed R reproduces the printed tables.
- **Inside air film:** optional (ASHRAE simplified equation for air in ducts); off by default, as in 3E Plus.
- **3D model:** galvanized rectangular or spiral duct, compressed wrap, FSK with foil-taped seams, pins under ducts 24" and wider, flat-topped stands. The effects run on the flat faces too.
- **Data:** `tools/build_ducts.py` generates `app/src/data/ductData.ts` from `research/duct-verified.json` (U-ids) and `research/code-requirements-verified.json` (C-ids).

**Recommend (Phase 6): answer a few questions, get a thickness.**
- **Pipe:** pick steel, copper or PVC and the size. Optional "what does it carry?" quick fills set typical temperatures from the presets. Choose indoors or outdoors, and mark condensate drains.
- **Duct:** pick the duct type and where it runs (with the location guide), the energy code and the climate zone.
- **Then:** set the temperatures and humidity, and choose an insulation or "best fit" (the thinnest that meets everything).
- **The answer:** the design thickness, with every requirement and its source — no condensation (dew point + 0.75°F), the energy code (ASHRAE 90.1 pipe or duct tables, or IECC for ducts), personnel protection and finish limits. The governing requirement is called out.
- **Extra notes:** the vapor-retarder check, outdoor protection (IECC C403.12.3.1), condensate-drain code status and the IMC 604.11 duct vapor retarder.
- **Alternatives:** the other insulations, compared side by side.
- **Recommend button:** nothing is calculated until you press **Recommend**. The answer lists the inputs it used; if you change an input afterwards, the answer greys out with an "inputs changed" notice until you press **Update recommendation**.
- **Open in the simulator:** hands the result to the matching tab.
- **Save as report (PDF):** Prepared by, Prepared for and Project fields; the report leads with the recommendation, its basis, the inputs, notes and alternatives, and reads on a phone.
- **Code:** `app/src/sim/recommend.ts`, tested in `recommend.test.ts`.

**Pipe energy codes:** choose the code in Setup, in Results (next to the code minimum) or in Recommend. The app opens on the Washington State Energy Code (King County) and then on whichever code and county were picked last on that device; every tab follows the latest pick (`app/src/sim/codePrefs.ts`). Engine defaults stay ASHRAE, so tests and shared files are unaffected.
- **ASHRAE 90.1-2019:** Tables 6.8.3-1 and 6.8.3-2.
- **IECC commercial:** 2021 Table C403.12.3; the same thicknesses as 90.1, except the 105–140°F conductivity range is 0.21–0.28.
- **IECC residential:** R403.4 requires R-3 above 105°F or below 55°F. The pipe R-value is ro·ln(ro/ri)/k, the IECC 2024 Table C403.13.3(1) definition.

**Washington State Energy Code (2021 WSEC, in effect since 3/15/2024)** — `research/wsec-verified.json` (W-ids), generated by `tools/build_wsec.py`:
- **Climate zone:** pick the county; WSEC Table C301.1 maps it to 4C or 5B.
- **Pipes, commercial:** Table C403.10.3, the IECC table with the below-40°F row rated at 75°F mean.
- **Pipes, residential:** R403.4 requires R-6 above 105°F or below 55°F; service hot water needs R-3 (R403.5.3).
- **Ducts (C403.10.1):**
  - Outside the building (including attics, crawl spaces and garages): R-8 in 4C, R-12 in 5B.
  - Unconditioned space: R-6, or R-3.3 when the duct air is within 15°F of the space.
  - Supply ducts in conditioned space carrying air below 55°F or above 105°F: R-3.3.
- **Outdoor-air and exhaust ducts:** the only code here with rules for them.
  - Outdoor air: R-16 between the outside and the shutoff damper, R-8/R-12 after it, R-7 for units under 2,800 cfm.
  - Exhaust or relief after the damper: R-16.
  - Downstream of energy recovery: R-8/R-12.

**Engine** (`app/src/sim/`): steady-state ASTM C680 approach.
- Conduction uses temperature-dependent k, integrated through the layer, from the manufacturer's published k-vs-mean points.
- The outer surface coefficient is the C680 form:
  - Churchill–Chu natural convection.
  - Churchill–Bernstein forced convection.
  - The C680 horizontal-pipe blend (j = 4, D = 0.3).
  - C680 air properties at the film temperature.
  - Radiation to ambient.
- Insulation OD comes from ASTM C585 where it is on file.
- The dew point uses Magnus (Alduchov & Eskridge).
- The condensation rate uses the Chilton–Colburn/Lewis analogy (Le = 0.847).
- Condensation control uses the 3E Plus / NIA 0.75°F margin.

**Checked by `npm test`** (`app/src/sim/validation.test.ts`):
- Bare pipe matches ASHRAE Fundamentals Table 17 within 0.7% median (2.1% max over 100 cells).
- NIA's calculators match within 0.4%.
- The 3E Plus sample printout matches within 1.1%.
- Owens Corning's 3E Plus condensation table is reproduced within ½" in 39/39 cells (31 exact).
- JM Micro-Lok HP tables are reported but not matched: they come from an unstated 3E Plus version and imply a k-curve above Micro-Lok's published values.

**Sources:**
- Every emittance, limit, preset range and method reference traces to `research/calc-method-verified.json` (M-ids), `research/emittance-verified.json` (E-ids), `research/validation-cases.json` (V-ids), `research/jackets-verified.json` (J-ids), `research/vapor-code-verified.json` (R-ids) `research/pipe-materials-verified.json` (G-ids), `research/duct-verified.json` (U-ids) or `research/code-requirements-verified.json` (C-ids). `tools/build_sources.py` regenerates the reference registry from those files.
- `app/src/sim/data.test.ts` fails if one doesn't.
- It is an educational / preliminary design tool, labelled as such in the app.

## Phone and offline

- **Framing:** on phones each tab fits its model between the bars at the top and the controls at the bottom (`useCovered` measures them), and refits when the bottom panel opens. Straight runs are seen more along the run, from the cut end. **Reset view** appears once the camera has been moved.
- **Controls:** one row (Insulated/Bare, Installed/Cutaway, or Location guide on Ductwork) and a labelled **More** menu for Compare, Thermal, Present and Reset view. Preset cards show once the panel is opened.
- **Bare stub tag:** the single view labels the bare stub ("Bare pipe – sweating", "Bare pipe · 250°F") from the engine's bare-pipe result, since the status pill describes the insulated run.
- **Download:** materials are created, and their textures fetched, only when a part uses them. Phones load half-resolution copies from `app/public/tex-half/`.
- **Install and offline:** a web app manifest and icons (`tools/gen_icons.py`) let it be added to the home screen. The service worker (`app/sw/sw.js`; `vite.config.ts` writes `dist/sw.js` with every built file and a content hash) saves the app on install; after the first view loads it saves every texture and lighting file the device uses, then says "Saved for offline use" once. Pages load from the network when it answers within 4 s, so a deploy shows straight away; a deploy re-downloads only files whose hash changed.

## Layout

| Path | What |
|---|---|
| `app/` | Vite + React + React Three Fiber app |
| `app/src/geo/` | Parametric geometry: `sweep.ts` (swept profiles) and `assembly.ts` (runs, elbows, valve, blanket) |
| `app/src/materials/` | PBR material factory and material slots |
| `app/src/data/` | Pipe sizes, material catalog, verified specs |
| `app/src/scene/` | Viewer, photo mode, mech room, callouts, simulation effects (`effects.tsx`) and thermal view (`thermal.ts`) |
| `app/src/sim/` | Calculation engine, model/solvers, presets, emittance, sources, learn copy, tests |
| `app/src/ui/sim/` | Simulator panels: setup, results, stage/compare, assumptions |
| `tools/gen_textures.py` | Generates every procedural PBR texture into `app/public/tex/` |
| `tools/half_textures.py` | Half-resolution phone copies into `app/public/tex-half/` (run by `gen_textures.py`) |
| `tools/gen_icons.py` | Home-screen icons into `app/public/icons/` |
| `app/sw/sw.js` | Offline service worker source (built into `dist/sw.js`) |
| `tools/shot.mjs`, `tools/matrix.mjs` | Headless screenshots and a smoke test of every combination |
| `tools/sim_shots.mjs` | Screenshots of each simulator mode (insulated, bare, thermal, compare); pass `390x844` for phone |
| `tools/bing_images.mjs` | Finds reference photos |
| `research/` | Construction notes, verified spec data, realism gap analysis, photo source records |

## Develop

```bash
cd app && npm install && npm run dev -- --port 5179
# textures (Python 3 + numpy, scipy, pillow):
python3 -m venv tools/.venv && tools/.venv/bin/pip install numpy scipy pillow
tools/.venv/bin/python tools/gen_textures.py            # all
tools/.venv/bin/python tools/gen_textures.py aluminum   # one group
tools/.venv/bin/python tools/half_textures.py            # phone copies only (gen_textures.py runs this itself)
```

`npm run build` produces a static site in `app/dist/`; `npm test` runs the engine and validation tests. Deep links: `?mode=hot|cold|condensate`, `&units=si`.
